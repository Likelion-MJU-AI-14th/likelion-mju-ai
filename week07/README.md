# 7주차 과제: GPT2 모델 지시 미세 튜닝

사전 학습된 gpt2-medium (355M) 모델을 다운로드 한 후 지시 미세 튜닝(Instruction fine-tuing)을 해보세요.

첨부된 `instruction-data.json` 데이터셋 파일은 저자가 제작한 1,100 쌍에 이번 북중미 월드컵 32강 토너먼트 결과와 대한민국 대표팀 이슈에 대한 내용을 추가한 버전입니다.

`instruction-data.json` 데이터셋으로 gpt2 모델을 지시 미세 튜닝 한 후 32강 토너먼트 결과 혹은 대표팀과 관련된 질문을 LLM에게 질의해보세요.

마지막으로 LLM의 답변을 스크린샷하여 같이 제출해주시면 감사하겠습니다.

## 진행 방법

1. 본인 이름 폴더로 이동합니다.
2. `train.py` 파일을 열고 TODO 리스트를 구현한 다음 모델을 미세 튜닝합니다.
3. `inference.py` 파일을 열고 북중미 월드컵 관련된 질문을 작성한 후 파일을 실행시키세요.
4. 구현한 코드와 모델 답변을 스크린샷 후 제출합니다.
