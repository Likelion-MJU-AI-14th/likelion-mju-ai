## 과제 안내

영상을 시청한 후, 간단한 감상문을 `.md` 형식으로 작성해주세요.

### 제출 형식

* 파일 형식: `.md`
* 파일명 예시: `week08_이름.md`
* 제출 방식: 기존 과제 제출 방식과 동일

### 작성 내용

감상문에는 아래 내용 중 일부를 자유롭게 포함하면 됩니다.

* 영상에서 가장 인상 깊었던 내용
* 새롭게 알게 된 점
* 본인의 생각이나 느낀 점
* 현재 스터디 내용과 연결해서 생각해볼 수 있는 부분
* 앞으로의 프로젝트나 학습에 적용해보고 싶은 부분

분량은 자유롭게 작성해도 괜찮지만, 단순 요약보다는 **본인의 생각이 드러나도록** 작성해주세요.
