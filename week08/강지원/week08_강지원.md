# 8주차 스터디 감상문

- 이름: 강지원
- 시청 영상: https://youtu.be/c88oWQfeo3Q?si=tuBQQ5oTJLOWu4tj

## 1. 인상 깊었던 내용

사이버 보안 취약점을 찾는 '미토스(Mythos)' 모델 이야기가 제일 인상 깊었습니다. OS 취약점을 뚫어버리는 걸 보고 '핵 바주카포'라고 부르던데, 앤트로픽이 상업적으로 돈을 엄청 벌 수 있는데도 위험성 때문에 대중 공개를 안 하고 소수 기관에만 풀었다는 게 대단하다고 느꼈습니다.

## 2. 새롭게 알게 된 점

AI 회사가 정부나 국방부랑 일할 때 윤리적으로 엄청난 갈등이 있다는 걸 처음 알았습니다. 그냥 기술만 좋으면 되는 줄 알았는데, 자율 살상 무기나 대규모 감시에 AI가 쓰이지 않도록 기업 차원에서 먼저 선을 긋고 국방부랑 부딪히는 걸 보면서, 기술 발전 속도만큼 윤리적 기준을 잡는 게 진짜 시급하다는 걸 배웠습니다.

## 3. 느낀 점

요즘 동아리에서 웹 해킹이랑 리버싱을 공부하고 있어서 그런지 미토스 모델이 남일 같지 않았습니다. 취약점 찾는 걸 AI가 다 해버리면 해커한테도 엄청난 무기지만, 결국 선한 의도를 가진 방어자가 더 뛰어난 모델을 쥐고 있어야 한다는 다리오 아모데이의 말이 확 와닿았습니다. 보안 공부하면서 기술적인 것만 파기 쉬운데, AI가 미칠 파급력이나 통제에 대한 부분도 평소에 같이 고민해 봐야겠습니다.

## 4. 스터디 또는 프로젝트에 적용해보고 싶은 점

이번 학기 진행 중인 프로젝트에도 미토스처럼 보안 취약점을 자동으로 찾아주는 AI를 무기처럼 적극적으로 활용해보고 싶습니다. 다만 다큐멘터리에서 본 것처럼, 그 힘을 방어적인 목적으로만 쓰겠다는 원칙을 저부터 세워두고 싶습니다.
